# Chouinard Studios Design References

This directory is the canonical home for approved visual reference material used to guide the Chouinard Studios website and brand implementation.

## Current Reference Direction

The approved visual reference set is based on the dream-studio imagery reviewed during Product Definition.

The design language includes:

- deep warm charcoal / near-black walls
- dark walnut hardwood
- Persian-style rugs and rich textiles
- burgundy / oxblood accents
- restrained brass / antique-gold detailing
- warm practical lighting and cinematic pools of light
- black leather seating
- acoustic clouds, diffusers, bass treatment, and architectural sound treatment
- premium guitar wall
- grand piano / Fazioli-style presence
- drum kit
- boutique amplifiers, including burgundy Two-Rock, Friedman, and Orange visual references
- microphones and recording hardware shown as working tools
- modern recording workstation embedded inside a timeless handcrafted environment

## Design Intent

The site should feel premium, warm, musical, cinematic, sophisticated, human, and craft-driven.

It should not feel corporate, sterile, SaaS-like, childish, generic, trend-driven, aggressively commercial, or like a gear showroom.

The central visual principle is:

Modern production capability inside a timeless, handcrafted creative environment.

## Image Reference Handling

Actual approved reference images should be added to this directory when available in the repository.

Until then, `BRAND-DIRECTION.md` and this document preserve the approved visual intent so implementation does not depend on memory or conversational context.

Do not substitute unrelated stock-studio imagery for the approved aesthetic without Product Lead / Founder review.
